# ห้องเรียนภาษาอังกฤษ ป.1–ป.6 • ครูเกียรติศักดิ์ กรุณา

เว็บไซต์สื่อการสอน Interactive SmartBoard สำหรับสอนภาษาอังกฤษระดับชั้นประถมศึกษาปีที่ 1–6 แบบแยกหมวดหมู่ รวมทั้งหมด **143 หมวดหมู่ 1226 คำศัพท์** พร้อมเกมฝึกทักษะหน้าห้องเรียน 5 โหมด รองรับทั้งคอมพิวเตอร์/กระดานหน้าชั้น และมือถือ (Light/Dark Theme + WCAG AA)

## โหมดการสอนและเกมหน้าห้องเรียน (5 โหมด)
1. **คำศัพท์ & โฟนิกส์** — แสดงภาพสี คำอ่านภาษาไทย การแบ่งพยางค์พร้อมเส้นโค้งและสีโฟนิกส์ + เสียงอ่านปกติและช้า
2. **ฝึกอ่านประโยค** — แตะคำศัพท์ทีละคำเพื่อออกเสียง พร้อมปุ่มฟังทั้งประโยคและคำแปลภาษาไทย
3. **เกมเติมประโยค** — ทายคำศัพท์ให้ลงช่องว่างในประโยคจากภาพและเสียงใบ้
4. **ฟังแล้วจิ้มภาพ** — ฟังเสียงคำศัพท์แล้วให้นักเรียนออกมาจิ้มภาพที่ถูกต้องบนหน้ากระดาน
5. **ทายศัพท์จากภาพ** — ดูภาพประกอบแล้วเลือกคำศัพท์ภาษาอังกฤษให้ถูกต้อง
